Not usable or not verifiable:
- **Rawpixel** returns 403 to every non-browser request, so I couldn't verify a single asset's licence; nothing from Rawpixel is shortlisted.
- **SVG Repo** rate-limited me (429).
- **Heritage Type** is paid, so nothing from it without your approval.
- **Postage stamps:** the only CC0 stamps I found (Smithsonian Postal Museum) carry US presidents, which is off-brand. Recommendation: no stamps, or I keep looking.

Evaluated and not recommended:
- React Bits CircularGallery: needs WebGL/ogl, too heavy for mobile.
- React Bits Masonry: pulls in Hugeicons.
- React Bits ScrollReveal: duplicates TextReveal, and GSAP is reserved for greeting scenes.
- Aceternity 3D Card: Tilt is already integrated.

Typography (optional): Cormorant Garamond (OFL) for Latin italics and small caps only. Georgian stays on Noto Serif Georgian, so the two scripts keep a matched weight.
