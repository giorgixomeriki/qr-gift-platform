# Minimal — "Just the words"

**Emotion:** clarity, quiet intimacy, modernity, personal focus.

**Avoid:** looking unfinished, a blank white page, Apple imitation, "no-design" design.

## Composition
A precise grid on bone paper. The message *is* the design: set large,
left-aligned, with a wide left margin. The opening line sits small above it
as a caption. One vermilion point marks the start of the message. A hairline
at the top edge and a tiny Starr at the foot. Nothing else.

## Palette
- Ground: bone `#ebe7e0`
- Card: paper white `#fdfbf7`
- Ink: `#1a1917`; soft ink `#6a655e`; the point in oxide `#c0472c`
- Accent: vermilion `#d2452a` (one point only)

## Type
- EN: Instrument Sans 400 (message set large), 500 caption
- KA: Noto Sans Georgian 350 / 450

## Material
Fine paper tooth, a crisp edge with almost no shadow.

## Artwork
One vermilion point and one hairline.

## Motion personality
Almost none — the type is the moment. **Signature — "the words resolve" (WOW pass):** the vermilion point lands first; each word rises from its own baseline, as if set by hand; the hairline is drawn and the opening line inked last. No decoration, no particles.

## Recipient reveal
The message itself is the event: the words appear, nothing else.
